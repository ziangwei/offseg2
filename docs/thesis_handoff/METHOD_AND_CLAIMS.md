# 最终方法：通俗解释、实现位置与可写结论

## 方法到底做了什么

OffSeg 已经能给当前图产生像素特征 F 和每类的参考向量 E。
参考向量来自全局学到的 W 加上当前图预测的偏移，不是用真值分组求像素均值。
我们的目标是在这个框架内改进类别判断，不增加属性预测分支，也不增加损失种类。

**第一步，补充跨图片经验。** 每个类别维护一份历史参考 P。
训练中把当前图的类别参考缓慢写进去；当前图对某类的预测总量少时，多参考历史，
预测总量多时，多保留本图的参考。这个“总量”是模型预测出来的软支撑，不是真实面积。
保存的是完整 E，而不是只有偏移。历史参考用 EMA 维护，没有梯度。
因此 EMA 是记忆的维护方式，不是完整方法的全部。

**第二步，让这份经验参与判断当前像素在和谁竞争。**
CCM 先用融合后的类别参考重新比较像素，累积保留覆盖 90% 类别概率的竞争者，
再把它们的参考按权重合成竞争上下文。上下文和像素特征一起经过小网络，
输出 64 个调节系数，对像素特征做低秩残差变换。
直观上，墙与门竞争、墙与柜子竞争时，允许使用不同的比较方式。
竞争者集合用于生成上下文，并不禁止最终输出集合以外的类别。
原始第一阶段分数仍负责第一阶段监督、支撑量和写库条件。

**第三步，用当前图的残差变化模式补充分数。**
IACS 为每类学四个全局方向。对每个像素，看它与该类参考之差在四个方向上的分量。
模型先得到各像素的类别倾向，再让更倾向该类的像素在该类统计里占更大权重，
汇总四个分量的大小及关联，形成当前裁剪、当前类别的 4×4 二阶矩。
该矩阵归一化后与单位阵混合，用来计算非负的二次修正分数。
最后加到中心匹配分数上，再做原有类别归一化。
这是加分型二次修正，不是“离子空间越远惩罚越大”、高斯似然或概率。

**每张新图到底改变什么？** 推理时网络参数 W、四个方向 U、混合参数、
历史库 P 都固定，不反向传播、不写测试图回记忆。
随输入重新计算的是 E、支撑量、融合权重、竞争上下文、像素调节系数、
残差二阶矩与修正分数。ADE 使用滑窗，所以这些图像条件量实际按窗口重算。
四个方向是固定坐标轴；4×4 矩阵是这张图在这些轴上的变化描述，下一窗口重新估计。
不存在推理时持续维护的“全局四维散布库”。

## 足够复核的方法细节

| 项目 | 原始最终配置/代码行为 |
|---|---|
| 类别记忆 | 每类一个 256 维向量，保存完整 E=W+偏移 |
| 写入资格 | 原第一阶段类别 softmax 在像素上的总和 >1；不是 GT 出现与否 |
| 多卡聚合 | 对符合条件的图像-类别对跨卡求等图像权重平均 |
| EMA 更新率 | 0.01；首次观察直接初始化，未见类别不混入零向量 |
| 预热 | 4000 步附近开始融合；读实现中的更新/判定顺序 |
| 融合 | λ=n₀/(n+n₀)，n₀ 从 200 开始，用 softplus 参数化学习 |
| CCM | 竞争概率累积阈值 0.9；低秩 64；上下文权重和参考停止梯度 |
| IACS | 每类秩 4，非中心二阶矩；先类别归一化，再对该类空间归一化的责任度 |
| 统计路径 | 停止梯度；特征与打分主路径继续训练 |
| IACS 混合 | 学到的全局混合标量；它小不等于 IACS 效果可以直接按它大小判断 |
| 损失 | 原第一阶段交叉熵 + 最终交叉熵，没有新损失类别 |
| 推理输出 | 最终分割一份；多一次中心匹配计算，不能写“没有计算开销” |

实现核对：

- `mmseg/models/decode_heads/offseg_head.py`、`OffSegCCM.py`：基础与 CCM。
- `OffSegACS.py`：`AffineClassSubspace`、`ImageAdaptiveAffineClassSubspace`，
  特别看 `assignment_statistics`、`image_metric`、`_subspace_correction`。
- `OffSegProtoMem.py`：`_update_prototypes`、`_blend_prototypes`。
- `OffSegProtoVariants.py`：`OffSegCCMIACSProtoRoute.forward`，只改 CCM 路由来源。
- `OffSegRouteAblations.py`：训练消融中实际删除了什么，而不是配置名猜测。
- `local_configs/offseg2/Base/offsegccmiacs_protoroute_r4_responsibility_ade20k_160k-512x512.py`
  及其父配置：完整方法 ADE-B。

## 贡献与证据边界

OffSeg、FreqFusion、类别子空间、软责任度/二阶矩、记忆库等都有既有研究来源。
正文应准确归因，不能把每个已有构件都列为原创。本文的实现贡献在于如何在
OffSeg 的图像类别参考、竞争上下文和残差评分之间组织并检验这套方法。
具体文献按 `THESIS_ROUTE.md` 的贡献边界与论文现有参考文献核对。

可写：当前 ADE-B 完整方法最高 48.49，六项移除/替代消融均较低；
静态 ACS 48.25 是接近完整方法的重要替代，责任度替为空间归一化降至 47.08。
这支持当前组合的经验有效性，但不能说明模块效果互相独立，也不能声称多种子显著性。

不能写：记忆只帮助小类；缺席类更依赖 P 就必然减少误报；λ 对自身支撑量的曲线证明学习有效；
Δ 热图亮就表示纠正成功；模拟空间权重的热图证明重新训练的空间消融会怎样；
Route 不增可训练参数就不增时延；GT 在前三类中的比例就是可实现的收益。

新材料如何增强论证：用两模型改对/改错统计连接机制图与最终预测；
用相同 GT 分区的两模型错误率比较内部/边界；用固定选择规则展示成功和失败；
把热图作为现象解释，训练消融作为模块有效性的另一路证据。
